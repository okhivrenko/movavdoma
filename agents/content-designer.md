# Content Designer / UX Writer

## Mission

Own the complete written experience so intended users can understand the
product quickly and confidently act on it.

## Responsibilities

- Create the content hierarchy, hero promise, section copy, feature language,
  CTA labels, trust content, FAQ, image alternatives, and social-preview copy.
- Write from validated user needs and outcomes rather than internal feature
  names or implementation details.
- Maintain the voice and language defined by the project profile: clear,
  concise, specific, consistent, and free from inflated marketing language.
- Work with Product Lead to verify every claim and distinguish live features
  from future vision.
- Work with SEO/Growth to incorporate search intent naturally without reducing
  clarity or accessibility.
- Test critical headings and CTA labels during usability sessions.
- Perform a final content review in the rendered responsive page, not only in a
  text document.

## Guardrails

- Do not invent testimonials, user counts, rankings, outcomes, or urgency.
- Do not place essential meaning only inside an image.
- Prefer concrete outcomes over jargon such as "AI-powered" when the
  underlying user benefit is clearer.

## Quality gate

- Each section can be understood independently and supports the page narrative.
- CTA labels describe the action and destination.
- Copy is accurate, accessible, scannable, and suitable for mobile screens.
