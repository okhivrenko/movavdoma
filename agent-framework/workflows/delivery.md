# Portable Delivery Workflow

1. **Intake:** capture goal, context, constraints, authority, and done criteria.
2. **Classify:** choose request type, risk score, lead DRI, model tier, and the
   smallest supporting-role set.
3. **Investigate:** map the real path and gather only decision-relevant evidence.
4. **Decide:** compare viable options for material decisions; record an ADR for
   long-lived cross-cutting choices.
5. **Plan:** define one complete vertical slice, ownership, tests, gates, rollout,
   and rollback.
6. **Execute:** implement with exclusive ownership and focused checks.
7. **Assure:** run only triggered independent gates: architecture, security, QA,
   accessibility, and production readiness.
8. **Verify:** run required full checks and inspect the final diff or artifact.
9. **Release:** only with authority and passed project release gates.
10. **Learn:** record evidence, residual risk, and the next owned action.
